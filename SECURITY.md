# Security policy

## Supported version

Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private security advisory reporting for this repository when it is enabled, or contact the project owner privately with:

- a clear description of the issue;
- steps to reproduce it;
- its potential impact; and
- any suggested mitigation.

The report will be acknowledged, investigated, and handled privately until a fix is available.
